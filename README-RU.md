# Арсенал: Android-прототип 0.1

Это новый нативный Android-проект на Java, а не полный перенос оригинальной DOS-программы. Оригинальные EXE/ADF не используются. Графика пока условная.

## Реализовано
- Карта 24 × 16 с рекой и проходом
- Три танка, выбор касанием, передвижение, поиск маршрута
- Пауза и перезапуск

## APK
GitHub Actions → Build Android APK → скачай артефакт Arsenal-Android-0.1 после успешной сборки.

Требования: JDK 17, Gradle 8.9, Android SDK 35.
