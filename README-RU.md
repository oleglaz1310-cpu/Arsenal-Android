# АРСЕНАЛ — Android-прототип 0.2

Это самостоятельная нативная Android-реализация на Java по мотивам A.R.S.E.N.A.L. Taste the Power, а **не перенос оригинального DOS-движка**. Оригинальные игровые файлы и графика пока не интегрированы.

## Что доступно сейчас

- Игровое поле 24 × 16 с рекой и проходом.
- Три танка и один бензовоз, выбор техники касанием и маршрутизация с обходом воды.
- Расход топлива при движении. При нулевом остатке техника останавливается и ждёт заправки.
- Бензовоз автоматически передаёт топливо танкам поблизости (радиус 2,25 клетки).
- Полоски топлива над игровыми клетками, информация о выбранной единице.
- Пауза, перезапуск и сохранение позиции, маршрутов и топлива при пересоздании Activity.
- Автоматические проверки модели в GitHub Actions.

## Как получить APK с телефона

Открой вкладку **Actions** репозитория, выбери последний успешный запуск **Build Android APK**.
В блоке **Artifacts** скачай архив `Arsenal-Android-0.1`, распакуй и установи `app-debug.apk`. Название артефакта историческое; сам интерфейс приложения теперь показывает версию 0.2.
